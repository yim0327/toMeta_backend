## About This Repository

본 레포지토리는 해커톤 심사 및 시연 기간 동안 다음 작업을 진행하기 위해 사용되었습니다.

* 서비스 배포 환경 대응
* Android WebView 연동 및 수정
* Health Connect 데이터 동기화 개선
* FCM 기반 알림 기능 개선
* 기록 작성 리마인더 스케줄링
* 일간 리포트 생성 로직 개선
* 운영 환경 CORS 및 쿠키 설정 보완
* Flyway Seed 및 Migration 추가
* 시연 과정에서 발견된 오류 수정

해당 기간의 **Issue, Pull Request 및 Commit 기록은 개발 이력 보존을 위해 본 레포지토리에 유지합니다.**
